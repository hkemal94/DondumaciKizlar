# Vitrin ve bar model adayları (9b, 15 Ekim akşam)

Kemal: "dondurma küvetlerinin gerçekle alakası olmadığını farkında mısın?
Bar konusunda komple assetlere ihtiyacımız olabilir." Kemal seçer; seçilen
modeller 9c ve 9d'de oyuna girer. Hepsi izinli CC0 paketlerden (Kenney Food,
Kenney Furniture, KayKit Restaurant, Tiny Treats Bakery ve Charming Kitchen).
Renkler paketteki gibi; oyuna girerken tasarım diline göre palete çevrilir.
Adlar yalnız tarif, kanon değil. Boylar gerçek ölçüye yakın (her sayfa kendi içinde).

| Dosya | İçerik |
|---|---|
| `1-vitrin-dolap.webp` | V0 koddan çizilen gelato vitrini, V1–V2 pasta camekânları, V3–V7 dolaplar |
| `2-makineler.webp` | M1 kahve makinesi, M2 espresso, M3 blender, M4 mikser, M5 kettle, M6 tost makinesi, M7 yazar kasa, M8 terazi |
| `3-bardak-sise.webp` | B1–B14 fincan, kupa, karton bardak, bardaklar, şişe, kutu, süt, kavanoz |
| `4-dondurma-meyve.webp` | D1–D8 külah, top, kâse, sundae, çubuk, krem şanti; D9–D12 meyve |
| `5-tezgah.webp` | T1–T10 bar tezgahı, tezgahlar, raf, tabureler, tepsi, menü |
| `6-gelato-vitrini-calisan.webp` | V0 çalışanın gördüğü açıdan: küvetlerde farklı doluluk (stok azaldıkça alçalır) |
| `7-gelato-vitrini-musteri.webp` | V0 müşteri tarafından: kavisli cam, boş fiyat kartları |

İzinli paketlerde gerçek bir dondurma vitrini (paslanmaz küvetler + kavisli
cam) yok. V0 bu yüzden koddan çizildi; seçilirse 9c'de oyundaki vitrinin
yerine geçer.

Sayfaları yeniden üretmek için: `aday/vb.html#sayfa=A` … `E`, `#sayfa=Y&aci=calisan|musteri`
(`aday/` klasörü depoya girmez; modeller paketlerden kopyalanır).
